# Kişisel Katalog (Personal Vault)

Kitap, tarif, tasarım referansları veya kişisel favorileri kategorize edip puanlamak ve tarayıcı hafızasında arşivlemek için geliştirilmiş minimalist bir web uygulaması.

**Canlı Demo:** [Uygulamayı Görüntüle](https://elapollon.github.io/kisisel-katalog/)

## Özellikler
- **Kayıt Ekleme ve Silme:** Başlık, kategori, 1-5 arası puan ve özel not ekleme.
- **Anlık Arama ve Filtreleme:** Kategori butonları ve metin aramasıyla kayıtları eşzamanlı süzme.
- **Veri Kalıcılığı:** `localStorage` desteği sayesinde sayfa yenilense bile veriler kaybolmaz.
- **Mobil Uyumlu Tasarım:** CSS Grid ve Flexbox ile farklı ekran boyutlarına otomatik uyum sağlar.

## Kullanılan Teknolojiler
- HTML5 (Semantik yapı)
- CSS3 (CSS Variables, Grid, Flexbox)
- Vanilla JavaScript (ES6+, DOM Manipülasyonu, Event Delegation, LocalStorage)
